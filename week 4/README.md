# Week 4 Logistics Predictive Modeling Project

## Dataset Overview
The dataset (`week4_logistics_predictive_model_dataset.csv`) contains 400 shipment entries tracking variables such as shipment distance, vehicle age, traffic index, weather risk, warehouse delays, and total delivery time.

## Repository Contents
- `Week_4_Predictive_Modeling_Logistics_Report.docx`: Technical report and analysis.
- `week4_logistics_predictive_model_dataset.csv`: Historical shipment dataset.
- `predictive_model.py`: Random Forest Regressor training script.
- `predictive_model_plot.png`: Feature importance & regression evaluation chart.
