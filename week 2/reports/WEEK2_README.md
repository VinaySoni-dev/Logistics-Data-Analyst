# Week 2 – Data Collection, Cleaning, and Preprocessing

This folder-level project update implements the second stage of the YUVA logistics analytics project.

## Objective

Prepare a reliable analytical dataset by:

1. Loading the public Olist dataset.
2. Profiling data quality.
3. Detecting duplicates and missing values.
4. Standardizing dates and categorical variables.
5. Creating delivery-time and late-delivery features.
6. Detecting potential outliers using the IQR method.
7. Demonstrating Min-Max normalization and StandardScaler standardization.
8. Validating the cleaned data.

## Main Notebook

Open:

`notebooks/week2_data_cleaning_preprocessing.ipynb`

## Main Python Modules

- `src/week2_cleaning.py` – data loading, profiling, cleaning, feature creation, and IQR bounds.
- `src/preprocessing.py` – Min-Max scaling, standardization, and validation helpers.

## Dataset

Download the Brazilian E-Commerce Public Dataset by Olist:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Place the CSV files in `data/`.

Do not upload the raw CSV dataset to GitHub.
